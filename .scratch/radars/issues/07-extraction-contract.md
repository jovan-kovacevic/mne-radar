# 07 — Settle the three holes in 'every page emits a record' before the extraction runs.

Type: task
Status: open
Blocked by: 01

## Question

Settle the three holes in 'every page emits a record' before the extraction runs.

1. **Page classification.** The 11 element-layout pages carry no PODACI
   PROJEKTA panel. Are they classified out before the double-blind read, so the
   corpus is 88 pages rather than 99?

2. **Which text is authoritative.** Every page carries the Montenegrin
   `PODACI PROJEKTA` panel *and* a burned-in English `SYSTEM REQUIREMENTS`
   overlay on the orthophoto. Per field: do readers transcribe the panel, and
   is the overlay forbidden as a source, or required as a cross-check?

3. **Self-contradicting records.** Loc 088 is named `dionica Berane - Rozaje`,
   has `Grad: GUSINJE`, and a coordinate roughly 30 km from that corridor. Which
   field wins? Does the record ship as printed, ship with the name suppressed,
   or block the build?

Resolve with a written extraction contract the run can be held to, and update
the validator list accordingly — the current validators check bbox, ID run,
25 m separation and enum membership, and would catch none of the above.
